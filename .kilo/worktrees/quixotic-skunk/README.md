# Product Pointers Backend

A NestJS application for product pointers.

## Prerequisites

- Node.js (v16 or higher)
- pnpm
- PostgreSQL
- typeorm
- nestjs

## Installation

pnpm install

## Generating and running database migrations

- pnpm run migration:generate
- pnpm run migration:run

## Running the app

- Make sure you have .env in the root
- pnpm run start:dev
